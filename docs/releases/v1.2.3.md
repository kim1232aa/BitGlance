## 比特一瞥 BitGlance 1.2.3

Windows 桌面 BTC / ETH / SOL USDT 永续价格小工具。

### 本版

- K 线滚轮缩放更可靠（`PreviewMouseWheel`）。
- 可见范围最高 / 最低价标注。
- 设置「迷你窗显示 K 线」：类交易所紧凑 K 线浮窗；默认仍为仅价格迷你窗。

### 使用

下载 `BitGlance-v1.2.3-Windows.zip`，解压后运行 `BitGlance.exe`。需要 Windows 10 / 11 和 .NET Framework 4.8。
